# Recall

Recall is a personal AI memory app for iOS. Save links, images, PDFs, and text through the Share sheet, then ask natural-language questions like "the chicken wings recipe" or "that coffee shop in Toronto."

## Repo

- GitHub: https://github.com/jwu0216/Recall.git
- Bundle ID: `com.jwu0216.recall`
- App Group: `group.com.jwu0216.recall`

## Windows development

1. Edit Swift files in Cursor
2. Commit and push to GitHub
3. GitHub Actions compiles on a macOS runner
4. For simulator testing, use MacinCloud and run `xcodegen generate`

## First push from Windows

```bash
cd /d/Recall
git add .
git commit -m "Initial Recall scaffold"
git push -u origin main
```

## Generate Xcode project on Mac

```bash
git clone https://github.com/jwu0216/Recall.git
cd Recall
xcodegen generate
open Recall.xcodeproj
```

Then select an iPhone simulator and press Run.

## Share extension testing

1. In Xcode, choose the `RecallShare` scheme
2. Run and pick Safari as the host app
3. Share a link or image to Recall

## OpenAI setup

Add your API key in the app under Settings. Recall uses it for embeddings, tagging, and chat answers.

## Project layout

- `project.yml` — XcodeGen project definition
- `Recall/` — main SwiftUI app
- `RecallShare/` — Share extension
- `RecallCore/` — shared models and services
- `.github/workflows/ios-build.yml` — compile-only CI (Phase A)

## Notes

- Do not commit `Recall.xcodeproj`; it is generated by XcodeGen
- Apple Developer account is only required for TestFlight / App Store (Phase B)
